# 🛡️ WatchOver — Women's Safety App

**Your Safety, Our Priority.**

## 🌍 About WatchOver

We are **Team WatchOver**, a group of developers working towards a safer and brighter India.

We live in a society where incidents affecting women's safety continue to be a serious concern. Although many existing applications provide emergency SOS buttons, we believe that women's safety should not be limited to getting help after an incident. It should also focus on **prevention, awareness, preparedness, and quick access to emergency resources**.

Our goal is to develop a web application that helps women stay informed, prepared, and connected to essential safety resources.

## 💡 Our Vision: Safety Before an Incident

We recognize that women's safety applications already exist. Instead of simply replicating their common features, we want to build upon them by focusing on preventive safety measures and a better user experience.

WatchOver combines essential safety features with thoughtful functionality, including smart input correction to help prevent mistakes while entering emergency contact information.

Our mission is to contribute to a safer India where women can feel more confident, prepared, and supported.

## ✨ Features

### Currently Implemented

- **Safety Tips:** Access useful safety information and awareness tips.
- **Emergency Contacts:** Manage important emergency contact information.
- **Safety Kits:** Explore safety-related products at reasonable prices.
- **SOS Button:** Access the emergency assistance interface.
- **Smart Contact Input Correction:** Helps correct accidental swapping of a contact's name and phone number.
- **Input and Form Validation:** Helps ensure that users enter information in the expected format.
- **Dynamic Routing:** Navigate to different services using dynamic routes.
- **404 Page:** Displays a dedicated page when a requested route is not found.
- **Context API:** Shares relevant application state across components.
- **Reusable Components and Props:** Supports component-based development and data sharing.
- **Responsive and Structured UI:** Organizes the application into accessible pages and reusable components.

### 🚀 Future Enhancements

We plan to expand WatchOver with the following features:

- **Live GPS Tracking:** Enable location sharing to support emergency assistance.
- **Nearby Police Stations:** Help users identify police stations near their current location.
- **Nearby Emergency Contacts:** Explore ways to identify and connect with relevant emergency resources based on location.
- **Enhanced Emergency Assistance:** Improve how users access safety resources during emergencies.

*These are planned enhancements and should not be considered fully implemented until they are developed and tested.*

## 🛠️ Technology Stack

- **Frontend:** React.js
- **Styling:** CSS
- **Routing:** React Router and dynamic routing
- **State Management:** React Context API
- **Component Communication:** Props
- **Validation:** Input validation and form validation
- **Build Tool:** Vite
- **Language:** JavaScript

## ⚙️ Getting Started

### Prerequisites

Install Node.js and npm on your computer.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/navneetpro93-commits/Watchover-A-Woman-Safety-App.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Watchover-A-Woman-Safety-App
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal to view the application.
